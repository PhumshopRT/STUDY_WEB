1. HTML5 Semantics

เลิกใช้ <div> ทุกที่! ใช้แท็กที่มีความหมาย เช่น <header>, <nav>, <main>, <section>, <article>, <footer> เพื่อ SEO และ Accessibility ที่ดี

🎨

2. Flexbox vs Grid

Flexbox เหมาะสำหรับ 1 มิติ (แถวเดียวหรือคอลัมน์เดียว) เช่น Navbar, Button group ส่วน Grid เหมาะสำหรับ 2 มิติ (ทั้งแถวและคอลัมน์พร้อมกัน) เช่น Card Grid Layout

⚡

3. Modern JS (ES6+)

ใช้ const / let แทน var, Arrow functions, Destructuring, Spread syntax ..., Template Literals, และ Async/Await แทน Promise chains ยาวๆ
