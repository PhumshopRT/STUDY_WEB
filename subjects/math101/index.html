MATH101 หมวด: คณิตศาสตร์

Calculus I: รวมสูตรดิฟ & อินทิเกรต

สรตรลัดอนุพันธ์ ฟังก์ชันตรีโกณมิติ กฎลูกโซ่ และเทคนิคการอินทิเกรต

อัปเดตล่าสุด: 18 พ.ย. 2026

✓ รวม 30 สูตรหลัก

📐 สูตรอนุพันธ์พื้นฐาน (Derivatives)

  • d/dx [ c ] = 0
  • d/dx [ x^n ] = n · x^(n-1)
  • d/dx [ e^x ] = e^x
  • d/dx [ ln(x) ] = 1 / x
  • d/dx [ sin(x) ] = cos(x)
  • d/dx [ cos(x) ] = -sin(x)

∫ สูตรอินทิเกรตพื้นฐาน (Integrals)

  • ∫ 1 dx = x + C
  • ∫ x^n dx = (x^(n+1))/(n+1) + C
  • ∫ (1/x) dx = ln|x| + C
  • ∫ e^x dx = e^x + C
  • ∫ cos(x) dx = sin(x) + C
  • ∫ sin(x) dx = -cos(x) + C

⭐ กฎลูกโซ่ (Chain Rule) ที่ออกข้อสอบบ่อยสุด

d/dx [ f(g(x)) ] = f'(g(x)) · g'(x)
